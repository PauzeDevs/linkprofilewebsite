# Link Profile Website

A responsive, single-page profile hub built with plain HTML, CSS, and JavaScript.

## Add your profiles

Open `index.html` and add entries to the `profiles` array near the bottom:

```js
{ name: "Instagram", handle: "@yourname", url: "https://instagram.com/yourname", icon: "IG" }
```

Each entry appears automatically as a profile card. Replace the starter GitHub profile with your own links and update the page title and description if needed.

## Run locally

Open `index.html` in a browser. No build step or dependencies are required.
